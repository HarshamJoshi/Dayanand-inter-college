# 🏫 Dayanand Inter College Website

Official website for **Dayanand Inter College, Pithoragarh**, designed to be a modern, responsive, and professional platform for students, parents, and faculty.

## 🌟 Key Features
- **Modern & Responsive Design:** Fully optimized for mobile, tablet, and desktop viewing.
- **10 Page Architecture:** Home, About, Admissions, Academics, Student Life, Notice Board, Gallery, Contact, Results, and Faculty.
- **Admin-Friendly Notice Board:** Easy-to-update notice system via `js/main.js`.
- **Performance Optimized:** Fast loading with clean, semantic HTML5 and Vanilla CSS.
- **Rich Aesthetics:** 3D floating elements, smooth transitions, and a professional color palette.

## 🛠️ Technology Stack
- **Structure:** HTML5 (Semantic)
- **Styling:** Vanilla CSS3 (Custom Design System)
- **Logic:** Vanilla JavaScript (ES6+)
- **Icons:** Custom SVG Icons
- **Imagery:** High-quality Unsplash integration

## 🚀 Local Development
To run the website locally:
1. Download or clone this repository.
2. Run the `start-server.ps1` script (on Windows) or open `index.html` directly.
3. Access at `http://localhost:3000`.
